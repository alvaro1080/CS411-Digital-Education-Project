def bubble_sort(a):
    for i in range(len(a)):
        for j in range(len(a)-i-1):
            if a[j] > a[j+1]:
                a[j], a[j+1] = a[j+1], a[j]

def merge_sort(a):
    if len(a) <= 1:
        return a

    mid = len(a) // 2
    left = merge_sort(a[:mid])
    right = merge_sort(a[mid:])

    return merge(left, right)

ALGORITHM A

Bubble Sort

Bubble Sort repeatedly compares neighboring elements. Its performance depends strongly on the initial order of the list.

Best case O(n) Worst case O(n²)

If the list is already sorted, Bubble Sort can finish after one pass when an optimized version is used.

M
ALGORITHM B

Merge Sort

Merge Sort divides the list into smaller pieces and merges sorted pieces together. The work stays much more predictable as the input grows.

Best case O(n log n) Worst case O(n log n)
!
THE KEY IDEA

Same task, very different strategies.

Bubble Sort can be very efficient on an already sorted list, while Merge Sort provides a more consistent performance. This is why we study best, average and worst cases.
