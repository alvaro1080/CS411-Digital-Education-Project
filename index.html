def merge_sort(a):
    if len(a) <= 1:
        return a

    mid = len(a) // 2
    left = merge_sort(a[:mid])
    right = merge_sort(a[mid:])

    return merge(left, right)

The observations reveal an important difference in how the two algorithms scale.

B
ALGORITHM A

Bubble Sort

Bubble Sort repeatedly compares neighbouring elements. In the worst case, many comparisons and swaps are required.

Best caseO(n)
Worst caseO(n²)
M
ALGORITHM B

Merge Sort

Merge Sort divides the list into smaller parts and merges them back in sorted order.

Best caseO(n log n)
Worst caseO(n log n)
!
KEY IDEA

Best case and worst case can be very different.

Bubble Sort can be surprisingly efficient when the list is already sorted, but its worst case grows much faster. Merge Sort keeps the same order of growth even when the input is difficult.
