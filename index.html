Cours : Les Algorithmes de Recherche

Bienvenue sur cette plateforme d'apprentissage ! Aujourd'hui, nous allons étudier l'un des algorithmes les plus simples et fondamentaux : la recherche linéaire (ou recherche séquentielle).

1. Le concept

La recherche linéaire consiste à passer en revue les éléments d'une liste un par un, du premier au dernier, jusqu'à ce que l'élément recherché soit trouvé ou que la liste soit entièrement parcourue.

2. Code d'exemple en Python

Voici comment implémenter cet algorithme de manière simple :

def recherche_lineaire(liste, cible):
    # Parcourir chaque élément avec son index
    for i in range(len(liste)):
        if liste[i] == cible:
            return i  # Élément trouvé ! On renvoie son index.
            
    return -1  # On a parcouru toute la liste sans rien trouver.

# Exemple d'utilisation :
ma_liste = [10, 23, 45, 70, 11, 15]
resultat = recherche_lineaire(ma_liste, 70)
print("Index de l'élément :", resultat) # Affiche 3

3. Complexité temporelle (Big-O)

  • Meilleur cas : O(1) — L'élément cherché est le tout premier de la liste.
  • Pire cas : O(n) — L'élément est à la toute fin ou n'existe pas dans la liste.
