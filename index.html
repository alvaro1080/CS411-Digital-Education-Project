ALGORITHM A

Bubble Sort

Sorting by neighbors

Bubble Sort compares neighboring elements. If they are in the wrong order, they are swapped. If a complete pass makes no swaps, the algorithm stops early.

def bubble_sort(a):
    for i in range(len(a)):
        swapped = False

        for j in range(len(a) - i - 1):
            if a[j] > a[j + 1]:
                a[j], a[j + 1] = a[j + 1], a[j]
                swapped = True

        if not swapped:
            break

    return a
ALGORITHM B

Merge Sort

Divide & conquer

Merge Sort repeatedly divides the array into smaller pieces, then rebuilds it by comparing the smallest available values.

def merge_sort(a):
    if len(a) <= 1:
        return a

    mid = len(a) // 2

    left = merge_sort(a[:mid])
    right = merge_sort(a[mid:])

    result = []

    while left and right:
        if left[0] <= right[0]:
            result.append(left.pop(0))
        else:
            result.append(right.pop(0))

    return result + left + right

ALGORITHM A

Bubble Sort

Bubble Sort repeatedly compares neighboring elements. With an optimized implementation, it can detect that the list is already sorted and stop immediately.

Best case O(n) Average case O(n²) Worst case O(n²)

The O(n) best case happens when the list is already sorted: one pass is enough to check all neighboring elements.

ALGORITHM B

Merge Sort

Merge Sort divides the list into smaller pieces and repeatedly merges sorted pieces together. The number of levels grows logarithmically.

Best case O(n log n) Average case O(n log n) Worst case O(n log n)
!
THE KEY IDEA

Same task, very different strategies.

Bubble Sort can finish quickly when the list is already sorted, while Merge Sort provides much more predictable performance as the input grows.
