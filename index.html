MISSION 01

The building blocks.

Already comfortable with these? Go straight to the experiment.

1 · Values

Storing information

A variable gives a name to a value, such as a number, some text, or a true/false answer. 

age = 19
name = "Ada"
is_sorted = False
2 · Conditions

Making decisions

An if runs some code only when a comparison is true. Sorting algorithms rely on this constantly. 

if a > b:
    print("a is bigger")
else:
    print("b is bigger or equal")
3 · Loops

Repeating work

A loop repeats the same instructions. A for loop runs a set number of times; a while loop runs as long as a condition holds. 

for i in range(3):
    print(i)        # 0, 1, 2

while x > 0:
    x = x - 1
4 · Arrays

Ordered collections

An array (a list in Python) holds many values. Each one has a position, called an index, starting at 0. 

a = [45, 23, 87]
a[0]               # 45
len(a)             # 3

# swap two neighbors
a[0], a[1] = a[1], a[0]
5 · Functions

Reusable recipes

A function packages instructions under a name. It can even call itself, which is called recursion. 

def double(x):
    return x * 2

def countdown(n):
    if n == 0:
        return
    countdown(n - 1)
