MISSION 01

The building blocks.

Already comfortable with these? Go straight to the search experiment.

1 · Values

Storing information

A variable gives a name to a value, such as a number, some text, or a true/false answer. 

age = 19
name = "Ada"
is_sorted = False
2 · Conditions

Making decisions

An if runs some code only when a comparison is true. Search algorithms rely on this constantly. 

if target == value:
    print("found")
else:
    print("keep looking")
3 · Loops

Repeating work

A loop repeats the same instructions. A for loop runs a set number of times; a while loop runs as long as a condition holds. 

for i in range(3):
    print(i)

while low <= high:
    mid = (low + high) // 2
4 · Arrays

Ordered collections

An array (a list in Python) holds many values. Each one has a position, called an index, starting at 0. 

numbers = [8, 12, 17, 23]
numbers[2]          # 17
len(numbers)        # 4
5 · Functions

Reusable recipes

A function packages instructions under a name. It can also call itself, which is called recursion. 

def linear_search(a, target):
    for i, value in enumerate(a):
        if value == target:
            return i
    return -1
