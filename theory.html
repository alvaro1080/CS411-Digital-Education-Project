The theory behind the two behaviors you observed.

B
ALGORITHM A

Bubble Sort

Bubble Sort repeatedly compares neighboring elements. With an optimized implementation, it can detect that the list is already sorted and stop immediately.

Best case O(n) Average case O(n²) Worst case O(n²)

The O(n) best case happens when the list is already sorted: one pass is enough to check all neighboring elements.

M
ALGORITHM B

Merge Sort

Merge Sort divides the list into smaller pieces and repeatedly merges sorted pieces together. The number of levels grows logarithmically.

Best case O(n log n) Average case O(n log n) Worst case O(n log n)
!
THE KEY IDEA

Same task, very different strategies.

Bubble Sort can finish quickly when the list is already sorted, while Merge Sort provides much more predictable performance as the input grows.
