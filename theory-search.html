Now let's explain what you saw.

The theory behind the two searching behaviors you observed.

L
ALGORITHM A

Linear Search

Linear search checks values one at a time from left to right. It is simple and flexible, but on a large list it may need to inspect many positions before it finds the target.

Best case O(1) Average case O(n) Worst case O(n)

Best case happens when the target is the first item checked. The algorithm works even when the list is unsorted.

B
ALGORITHM B

Binary Search

Binary search repeatedly splits a sorted list into halves and discards the half that cannot contain the target. This makes it much faster on large sorted inputs.

Best case O(1) Average case O(log n) Worst case O(log n)

Binary search depends on the list being sorted. If the data is not ordered, it can no longer safely ignore halves.

!
THE KEY IDEA

Same question, different strategy.

Linear search gives up little and works almost anywhere; binary search is much faster after sorting, because it throws away half the list each step.
