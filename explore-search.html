ALGORITHM A

Linear Search

Check one by one

Linear search starts at the beginning and checks each value in order until it finds the target. It does not need the list to be sorted.

def linear_search(a, target):
    for i, value in enumerate(a):
        if value == target:
            return i
    return -1
ALGORITHM B

Binary Search

Cut the list in half

Binary search only works on sorted data. It checks the middle element, then decides whether to keep the left or right half and continues narrowing the search.

def binary_search(a, target):
    low, high = 0, len(a) - 1

    while low <= high:
        mid = (low + high) // 2
        if a[mid] == target:
            return mid
        if a[mid] < target:
            low = mid + 1
        else:
            high = mid - 1

    return -1
